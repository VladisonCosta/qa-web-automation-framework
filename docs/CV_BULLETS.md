## QA Web Automation Framework — Projeto Pessoal
- Desenvolvi uma suíte de testes automatizados E2E em Java com Selenium WebDriver e JUnit 5 para fluxos críticos de autenticação, catálogo, carrinho e checkout.
- Estruturei a automação com Page Object Model, esperas explícitas, testes positivos e negativos, tags de smoke/regressão e captura automática de screenshots em falhas.
- Documentei plano de testes, casos de teste, matriz de rastreabilidade e modelo de reporte de bugs.
- Integrei a suíte ao GitHub Actions para execução headless em CI e geração de evidências de teste com Allure.

**Tecnologias:** Java, Selenium WebDriver, JUnit 5, Maven, Allure Report, GitHub Actions.
